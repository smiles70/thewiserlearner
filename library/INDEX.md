# Library Index

This file is the master list of verified geragogy sources cited anywhere in the
project. Every entry in `library/` is one Markdown file whose front-matter is the
canonical record of a single source. Scripts cite entries by ID (e.g. `[L-007]`).

## Conventions

- File name: `L-NNN-<first-author-lastname>-<year>-<short-slug>.md`
- Sources are added only through a Pull Request that follows the
  [`library_source` issue template](../.github/ISSUE_TEMPLATE/library_source.md)
  and includes triple-verification evidence.
- Sources that fail any verification step go to `_candidates/` and are never cited.

## Triple-verification checklist (must be recorded in each entry's front-matter)

1. OpenAlex record found and matches title + first author + year.
2. Crossref record found via DOI and matches title + first author + year.
3. Publisher landing page is HTTP-200 and matches title + first author + year.
